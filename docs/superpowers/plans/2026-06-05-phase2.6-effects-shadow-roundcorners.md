# Phase 2.6 Effects (Drop Shadow + Round Corners) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add two optional object effects to the Phase 1 Effects system — a configurable drop shadow (`obj.shadow`) emitted as a shifted dark `VGroup` copy, and rounded corners for polygon/triangle/star via Manim's native `round_corners` (reusing the existing `cornerRadius` field).

**Architecture:** Two byte-identical codegen helpers (`shadowLines`, `roundCornersLine`) appended in the existing post-construction effect block (next to `gradientLine`/`dashedLines`), a Konva native-shadow + corner-rounding preview in `applyEffects`/shape cfgs, an extended "Effects" inspector panel, a round-trip parser, and a `setShadow` store action. Absent fields ⇒ byte-identical legacy output.

**Tech Stack:** Vue 3 `<script setup>`, Pinia, Konva (vue-konva), Manim CE codegen (codegen.js + manim.js byte-identical), Vitest.

**Spec:** `docs/superpowers/specs/2026-06-05-phase2.6-effects-shadow-roundcorners-design.md`.

**Parity rule (codegen tasks):** `services/api/src/compiler/codegen.js` (`objectCode`) and `services/web/src/export/manim.js` (`objCode`) share no import; new helpers, sets, and call-site lines must be **byte-identical** between them, guarded by `manim-export.test.js`. The post-construction effect block is at manim.js ~506-510 and codegen.js ~515-517 (identical shape). Module constants `FRAME_WIDTH`/`FRAME_HEIGHT` and the `hex(...)` helper are in scope in both files.

**Key distinction (two "round" sets):**
- Inspector `ROUND_TYPES` / `canRound` (which types show the `cornerRadius` control): extended to `{rectangle, square, polygon, triangle, star}`.
- Codegen `roundCornersLine` (which types emit `.round_corners()`): **only** `{polygon, triangle, star}` — rect/square keep their existing `RoundedRectangle` path.

```js
/** round_corners line for polygon/triangle/star (rect/square use RoundedRectangle), or null. */
function roundCornersLine(n, obj, sw) {
  if (!obj.cornerRadius || obj.cornerRadius <= 0) return null;
  if (!['polygon', 'triangle', 'star'].includes(obj.type)) return null;
  return `${n}.round_corners(radius=${(obj.cornerRadius / sw * FRAME_WIDTH).toFixed(3)})`;
}
/** Drop-shadow lines (shifted dark copy + VGroup), or [] when no shadow. */
function shadowLines(n, obj, sw, sh) {
  const s = obj.shadow;
  if (!s || !SHADOW_TYPES.has(obj.type)) return [];
  const color = hex(s.color) || '"#000000"';
  const op = +(Number.isFinite(s.opacity) ? s.opacity : 0.4);
  const dxm = ((Number.isFinite(s.dx) ? s.dx : 8) / sw * FRAME_WIDTH).toFixed(3);
  const dym = ((-(Number.isFinite(s.dy) ? s.dy : 8)) / sh * FRAME_HEIGHT).toFixed(3);
  return [
    `_shadow_${n} = ${n}.copy().set_color(${color}).set_opacity(${op}).shift([${dxm}, ${dym}, 0])`,
    `${n} = VGroup(_shadow_${n}, ${n})`,
  ];
}
```

```js
    // round_corners(radius=...) → restore cornerRadius (px) on polygon/triangle/star
    m = line.match(/^(\w+)\.round_corners\(radius=([-\d.]+)\)/);
    if (m) {
      const t = objById[varMap[m[1]]];
      if (t && ['polygon', 'triangle', 'star'].includes(t.type)) {
        t.cornerRadius = Math.round(parseFloat(m[2]) / FRAME_WIDTH * sw);
      }
      continue;
    }

    // Drop-shadow copy line → stash by base var
    m = line.match(/^_shadow_(\w+)\s*=\s*\w+\.copy\(\)\.set_color\("([^"]+)"\)\.set_opacity\(([-\d.]+)\)\.shift\(\[([-\d.]+), ([-\d.]+), 0\]\)/);
    if (m) {
      pendingShadow[m[1]] = {
        color: m[2], opacity: parseFloat(m[3]),
        dx: Math.round(parseFloat(m[4]) / FRAME_WIDTH * sw),
        dy: Math.round(-parseFloat(m[5]) / FRAME_HEIGHT * sh),
      };
      continue;
    }

    // Shadow VGroup wrapper → attach the stashed shadow to the base object
    m = line.match(/^(\w+)\s*=\s*VGroup\(_shadow_(\w+), \2\)/);
    if (m) {
      const ps = pendingShadow[m[2]];
      const t = objById[varMap[m[2]]];
      if (ps && t) { t.shadow = { ...ps, blur: 12 }; delete pendingShadow[m[2]]; }
      continue;
    }
```
